# Scope

This Working Group develops the FPSOT naming specification.

The specification covers the identifiers that machines read in FPSOT projects: repository names, Java and Kotlin package names, Maven coordinates, address paths, JSON field and query parameter names, event types, code list values and file names in specification repositories. It sets their language, characters, case styles, word forms and length, and when they may change.

It does not cover labels and other text that people read, nor names inside source code such as classes and variables.

Any changes of Scope are not retroactive.
