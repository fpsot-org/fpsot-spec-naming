This guide explains the {abbr-fpsot-first} naming specification for the teams that adopt it.

== Why names stay in English

A name is part of a contract between programs.
Code, stored data and logs all repeat it.
If each language had its own name, every interface would need two versions, and they would drift apart.

People never need to see a name.
A screen shows a label instead, in the language of the reader.
The label comes from the code list or the interface text, and a translator can improve it at any time.
The name stays the same for the whole major version.

== Where the words come from

The writing specification keeps a term base in English and in French.
A name takes the English term of an entry.
The screen shows the term in the language of the reader.
For example, the field `assetId` shows the label "Asset" in English and "Bien" in French.
