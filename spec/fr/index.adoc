= Spécification FPSOT sur le nommage
include::_fpsot-terms.adoc[]

Cette spécification fixe comment les projets de la {abbr-fpsot-first} nomment les identifiants que les machines lisent.
Elle couvre le nom de chaque {term-repository}, de chaque paquetage et de chaque fichier.
Elle couvre aussi les chemins de chaque {abbr-uri-first}, les champs des données {abbr-json-first} et les paramètres de requête.
Les types d'événements et les listes de codes complètent la liste.
Les libellés et les autres textes que les personnes lisent suivent plutôt la spécification de rédaction.
Les noms internes au code source, comme les classes et les variables, relèveront d'une future spécification sur le code.

La spécification comporte les parties suivantes.

* Les xref:principles.adoc[principes] s'appliquent à tous les noms.
* La partie xref:case.adoc[Casse et forme des mots] fixe le style de casse de chaque contexte.
* La partie xref:repositories.adoc[Dépôts et paquetages] couvre les dépôts, les paquetages Java et Kotlin et les coordonnées Maven.
* La partie xref:paths.adoc[Chemins] couvre la partie chemin de chaque adresse.
* La partie xref:fields.adoc[Champs] couvre les noms dans les données.
* La partie xref:events.adoc[Événements] couvre les types d'événements.
* La partie xref:code-lists.adoc[Listes de codes] couvre les valeurs codées et leurs libellés.
* La partie xref:files.adoc[Fichiers] couvre les noms de fichiers des dépôts de spécification.
* La partie xref:stability.adoc[Stabilité] indique quand un nom peut changer.

== Conformité

[quote, 'link:https://www.rfc-editor.org/info/rfc8174[RFC 8174]']
____
The key words "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT", "SHOULD", "SHOULD NOT", "RECOMMENDED", "NOT RECOMMENDED", "MAY", and "OPTIONAL" in this document are to be interpreted as described in BCP 14 (link:https://www.rfc-editor.org/info/rfc2119[RFC 2119], link:https://www.rfc-editor.org/info/rfc8174[RFC 8174]) when, and only when, they appear in all capitals, as shown here.
____

Les mots clés suivent l'exigence WRT-010 de la spécification de rédaction de {abbr-fpsot}.
La version française emploie les mots clés français de l'exigence WRT-011.

Un produit est conforme à cette spécification si chaque nom qu'il publie respecte toutes les règles DOIT.
Un nom publié est un nom dont un autre programme, un enregistrement stocké ou un document peut dépendre.
