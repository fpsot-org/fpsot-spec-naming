= FPSOT naming specification
include::_fpsot-terms.adoc[]

This specification sets how {abbr-fpsot-first} projects name the identifiers that machines read.
It covers the names of each {term-repository}, package and file.
It also covers the paths of each {abbr-uri-first}, the fields of {abbr-json-first} data, and query parameters.
Event types, telemetry attributes and code lists complete the list.
Labels and other text that people read follow the writing specification instead.
Names inside source code, such as classes and variables, belong to a later coding specification.

The specification has these parts.

* xref:principles.adoc[Principles] apply to every name.
* xref:case.adoc[Case and word form] sets the case style of each context.
* xref:repositories.adoc[Repositories and packages] covers repositories, Java and Kotlin packages and Maven coordinates.
* xref:paths.adoc[Paths] covers the path part of each address.
* xref:fields.adoc[Fields] covers the names in data.
* xref:events.adoc[Events] covers event types and telemetry attributes.
* xref:code-lists.adoc[Code lists] covers coded values and their labels.
* xref:files.adoc[Files] covers file names in specification repositories.
* xref:stability.adoc[Stability] says when a name may change.

== Conformance

[quote, 'link:https://www.rfc-editor.org/info/rfc8174[RFC 8174]']
____
The key words "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT", "SHOULD", "SHOULD NOT", "RECOMMENDED", "NOT RECOMMENDED", "MAY", and "OPTIONAL" in this document are to be interpreted as described in BCP 14 (link:https://www.rfc-editor.org/info/rfc2119[RFC 2119], link:https://www.rfc-editor.org/info/rfc8174[RFC 8174]) when, and only when, they appear in all capitals, as shown here.
____

The keywords follow requirement WRT-010 of the {abbr-fpsot} writing specification.
The French version uses the French keywords of WRT-011.

A product conforms to this specification when every name it publishes meets every MUST rule.
A published name is one that another program, a stored record or a document can depend on.
